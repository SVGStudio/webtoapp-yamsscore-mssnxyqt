# Yams Score

Application Android générée par WebToApp à partir de https://www.yams-bysvg.base44.app.

## Option 1 — Obtenir l'APK sans Android Studio (recommandé, gratuit)

1. Créez un compte gratuit sur https://github.com si nécessaire.
2. Créez un nouveau dépôt (New repository) et importez ce dossier
   (glissez-déposez les fichiers, ou utilisez GitHub Desktop).
3. Dès le push, GitHub Actions compile automatiquement le projet.
4. Allez dans l'onglet Actions de votre dépôt > cliquez sur le build réussi.
5. En bas, section Artifacts > téléchargez apk (et/ou aab).
6. Décompressez : vous obtenez votre vrai fichier .apk installable sur Android
   (activez Sources inconnues sur le téléphone pour l'installer).

## Option 2 — Android Studio

1. Ouvrez Android Studio > Open > sélectionnez ce dossier.
2. Build > Build Bundle(s) / APK(s) > Build APK(s).
3. Pour la Play Store : Build > Generate Signed Bundle / APK > Android App Bundle.
